# UX Contract — ОРБИТА

## Product context
Руководитель читает 10 аналитических дашбордов; разработчик подключает GET API в настройках. UA по умолчанию, EN/RU через сохранённый переключатель, locale-aware числа, временные метки Europe/Kyiv, метаданные отчёта из API. Цель — WCAG 2.2 AA в браузере; XR проверяется отдельно в шлеме.

## Navigation and dataset
Фиксированные 10 карточек — render all, без пагинации. Вкладки навигации: обзор, платежи, кассы, оборудование; `?view=` восстанавливает выбор и Back/Forward. `?admin=1` открывает настройки. Никаких токенов/URL API в адресной строке. Дата — read-only метаданные, не фиктивный фильтр.
Фокус: кнопка каждой карточки открывает подробную визуализацию и таблицу точных данных. Escape и «Закрыть» возвращают фокус на исходную кнопку. Одинаковое поведение у всех 10 карточек.

## Async and resilience
GET с таймаутом 4000мс, отмена/номер поколения защищают от старого ответа при смене конфигурации. Polling последовательный, без наложения запросов. Интервалы 0/5/15/30/60с. Mock читает локальный JSON. Состояния источника mock / simulation / live / fallback / error честные.
Последний live-снимок только в памяти. localStorage хранит только демоданные и несекретные настройки. Синхронизация BroadcastChannel + storage только демоданных. Симуляция живёт в активировавшей вкладке, второй запуск в другой вкладке прекращает предыдущий через канал. Конфликт JSON-редактора сообщает о новой версии, не затирает набранный текст.

## Forms and overlays
noValidate, Zod, явные label, aria-invalid + aria-describedby, фокус первого ошибочного поля. Нативные select используют OS-popup намеренно. Textarea resize:none, большой редактор прокручивается. Bearer token masked, reveal button, только память. Endpoint HTTPS или относительный /api путь; HTTP допустим только для localhost-разработки, URL credentials/query/hash запрещены. Поля не очищаются при ошибке.
Radix Modal владеет focus trap, inert background, Escape, возвратом фокуса. Нет alert/confirm/prompt. Toast — одна aria-live область; ошибки API остаются в статусе/форме. Unsaved guard на закрытие и beforeunload; смена вкладок внутри настроек не теряет поля.

## Verification
Unit: схемы, границы простоев, данные всех десяти моделей, сценарии, fallback/strict/timeout. Browser: панорама, три блока, 10 фокусов, настройки, невалидный JSON, синхронизация, keyboard, mobile, reduced motion, две темы, axe. XR: рендер WebGL и fallback без поддержки; фактические контроллеры/руки/passthrough/оптика требуют Quest 3S. Commands/results — docs/WORKLOG.md и docs/VERIFICATION.md.

## Пространственная навигация
Выбор любой из 10 карточек открывает подробный фокус. В нём «Предыдущий дашборд» / «Следующий дашборд» меняют карточку в пределах 1–10; на границах соответствующая кнопка disabled. «К панораме» снимает фокус. Внутри XR эти же действия доступны на mesh-кнопках под карточкой; в браузере — через native select и DOM-кнопки с именами. Статус сообщает текущую карточку. Изменение фокуса не перемещает камеру.

Переключатель окружения в предпросмотре использует общий theme приложения. «Развернуть 3D-просмотр» увеличивает область canvas в том же диалоге; scroll owner остаётся диалогом. Фото в browser preview декоративное; реальный AR требует совместимого шлема. Source: docs/SPEC.md §1.3 и docs/DECISIONS.md.

## Упрощение визуала и 3D-кабинет · 2026-10-17
Названия вместо декоративных номеров во всех DOM/XR-представлениях. Нет постоянных рамок панелей и акцентных штрихов у заголовков. Hover XR осветляет поверхность, focus-visible браузера остаётся явным. Аналитические величины и семантика цветов не меняются.

Комнатой владеет spatial/ProceduralRoom.tsx, материалами — DESIGN.md. Одна геометрия для browser preview и VR, не монтируется в immersive-ar. «Осмотреть комнату» доступно в браузере независимо от наличия данных: скрывает карточки и селектор, разрешает поворот ±180°; возврат очищает фокус и yaw. Настройки источника/данные не меняются. В XR эта функция недоступна; вход/выход возвращает панораму. Неподдерживаемый WebGL по-прежнему имеет объяснение и обычный обзор.

## Минимум видимого текста · 2026-10-17
Предметные заголовки, единицы, план/период и состояния остаются. Дубли источника/описаний/инструкций/счётчиков удалены. XR имеет одну общую строку source+period в реальном mesh и sr-only DOM-альтернативу. Имя выбранной карточки в статусе sr-only, native select остаётся видимым. DowntimeLabel доступен в aria-label/tooltip вместо повторной видимой строки под каждой дугой. Ошибки, восстановление, конфликт и unsaved guard сохраняют действие/последствие; Bearer token по-прежнему только в памяти вкладки.

## Обновления PWA
Новая production-сборка ожидает явного «Обновить приложение». Проверка выполняется при регистрации, возвращении на вкладку/окно и восстановлении сети; отсутствие сети не блокирует аналитику. Применение перезагружает только выбравшую его вкладку, поэтому токен после неё нужно ввести снова по существующему контракту. Открытый диалог и unsaved guard не обходятся. Другим вкладкам предлагается обновление, без перезагрузки.

Миграция старой PWA, в которой отсутствовала кнопка, выполняется один раз: worker активируется без принудительной перезагрузки обычных вкладок. Ссылка `?orbita-update=1` явно обновляет только открывшую её вкладку в точном корне scope. Маркер удаляется из URL. Несекретные настройки/демоданные не очищаются; cache marker протокола относится только к данному scope. Отсутствие этого marker не мешает offline-демо. После миграции следующие worker ждут явного применения. Проверка upgrade использует историческую настоящую сборку, две вкладки, черновик и offline после обновления.

## Пространственная доработка интерфейса · 2026-10-17
Боковая панель desktop сохранена по прямому требованию пользователя; на телефоне её заменяют вкладки с тем же именем «Вид аналитики», URL-состоянием и действиями. Одновременно видна только одна навигация. Нижней плавающей панели нет; настройки доступны как «Источники данных» в sidebar или верхней строке телефона, помощь — там же. Дата под заголовком остаётся read-only. Краткость чисел и обновление данных находятся рядом с входом в пространство.

Modal остаётся владельцем фокуса. В обычном подробном просмотре «Предыдущий дашборд» / «Следующий дашборд» меняют карточку без закрытия; границы 1 и 10 disabled. При открытии и смене карточки подробная таблица развёрнута, её заголовок и строки относятся к новой модели. Escape возвращает фокус на исходную карточку обзора, даже если внутри диалога пользователь перешёл к другой. Это те же границы, что в XR; камера и XR-контроллеры не меняются.

Обычный запуск E2E пишет JSON и скриншоты в ignored test-results/, историческое docs/evidence больше не перезаписывается автоматически. Новые визуальные доказательства для конкретного изменения выбираются и сохраняются отдельно.

## Локализация и материалы · 2026-10-17
Актуальное поручение: docs/source/spatial-localization-request-2026-10-17.md. Переключатель UA/EN/RU в шапке и настройках хранит только предпочтение orbita-locale и синхронизирует вкладки. document.lang, доступные имена, формат чисел, периоды, источник и тексты canvas меняются без перезагрузки. Неизвестные пользовательские строки API остаются нетронутыми; язык не изменяет данные или валюту.

Панели имеют направленный мягкий свет на верхнем/левом краю и стабильный слой контраста над комнатой. Появление панелей не меняет непрозрачность текста. Дата и заголовки разделов — матовые капсулы. На компьютере три колонки используют общие строки сетки; месячный переключатель находится внутри карточки количества/объёма. На телефоне вкладки прокручиваются внутри своего контейнера, сохраняя названия и области нажатия от 40px.

DOM-планы/простой представлены горизонтальными meters: точный процент виден даже при перевыполнении, заполнение ограничено 100%, aria-valuetext сохраняет точное значение. Факт и план 100% явно разделены. Числовой план из округлённого процента не придумывается. Простой использует отдельную семантику (≤2 низкий, ≤6.5 рабочий, выше высокий). Детальная таблица раскрыта по умолчанию; заголовки/единицы всегда соответствуют языку и источнику.

Настройки открывают вкладку текущего источника: mock → Демонстрация, hybrid/live → API. В Demo поля URL/token/источник скрыты. Открытие вкладки API переводит только черновик mock→hybrid; сохранение остаётся явным действием. Смена вкладок и демосценариев не уничтожает несохранённый URL/токен. Вкладки поддерживают Arrow/Home/End, single focus ring сохраняет видимость клавиатурного фокуса.

## Актуализация · 2026-10-18
Полный обзор по умолчанию показывает 10 самостоятельных карточек; месячный переключатель позволяет явное сужение. Мобильные подписи короткие, все четыре вкладки помещаются на 360px; полные доступные имена разделов сохранены. Фокус имеет контекст предыдущего/следующего дашборда и прямой переход 1–10. Таблица: показатель, факт, план/порог, выполнение/статус. Числовой план, отсутствующий в API, не вычисляется.

Планы используют динамический максимум не ниже 120%, отметку 100% и точный aria-valuenow. Простой имеет отдельную шкалу риска с указателем, максимумом не ниже 10% и порогом внимания 6,5%, а не вымышленным SLA 5%. «Зоны внимания» открывают соответствующий фокус. Выбор демосценария определяется по фактическому dataset; при ручной правке/симуляции не показывается ложная активность старого сценария.

XR-группы переключаются в одной фронтальной области; все 10 моделей остаются доступны. Пространственные точные значения имеют страницы по три факта, доступные mesh-кнопками и через DOM. Перецентровка переставляет рабочую область, не XR-камеру. Активный XR рендерится каждый кадр, browser — demand. Старые пункты о трёх одновременных высоких стендах и клиппинге плана на 100% заменены этой записью.
