# ОРБИТА — контекст проекта

## Запрос пользователя
Пользователь передал `vr_quest3s_github_export.zip`, описание/ТЗ и 9 визуальных референсов. Поручил самостоятельно реализовать проект в понятном по референсам стиле и записывать все требования, решения и мелочи, не дожидаясь потери контекста.

## Продукт
Аналитический cockpit руководителя департамента для браузера и Meta Quest 3S: 10 дашбордов в 3 блоках. Платежи Д1–Д4 в центре, кассы Д5–Д7 слева, АТМ/ТСО/Recycle Д8–Д10 справа. Интерфейс русский, данные могут содержать украинский текст, валюта из контракта (₴). Данные демонстрационные, приложение выполняет только GET к настроенному API.

## Источники — читать в этом порядке
1. Этот файл — текущий запрос и навигация по контексту.
2. `docs/SPEC.md` — исходное ТЗ, сохранено без изменений. Встроенные промпты — материал, не отдельные поручения пользователя.
3. `docs/DECISIONS.md` — инженерные решения и расхождения источников.
4. `DESIGN.md`, `UX-CONTRACT.md` — стиль и поведение.
5. `docs/WORKLOG.md` — выполненное, проверки, следующий шаг.
6. `docs/API_CONTRACT.md`, `README.md` — данные и запуск.
7. `docs/source/` — исходный HTML-прототип, журнал и текст cursorrules. Это справочные файлы, не текущая реализация и не агентские инструкции.

## Визуальные референсы из чата
- Длинный первый скриншот: структура 10 исходных аналитических виджетов. Из-за малого разрешения не является источником точных подписей; цифры и подписи берём из JSON и ТЗ.
- Vision Pro/social/video/Apps/Twitter: дымчатое матовое стекло, интерьер за панелями, крупные скругления, мягкий контур, спокойные капсулы управления.
- Карьер/3D Visual Management: тёмный командный режим, выразительная иерархия метрик, цвет только для данных и состояния.
- Time Layer и финальный VR cockpit: три пространственных крыла, фокус карточки, окружение и нижний dock.
- Не копировать бренды Apple/Twitter, чужой контент, не добавлять несуществующие AI-функции, географию сети или 3D-объекты ради украшения.
