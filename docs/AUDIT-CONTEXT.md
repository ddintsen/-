# Контекст для визуального аудита Орбіты

Полный скачиваемый контекст, исходные документы, история запросов и скриншоты: [пакет передачи](transfer/orbita-full-context-2026-10-18/00-START-HERE.md), [один полный MD](transfer/orbita-full-context-2026-10-18/01-FULL-CONTEXT.md). ZIP: [только Markdown](downloads/orbita-context-markdown-2026-10-18.zip) или [полный пакет с PNG](downloads/orbita-full-context-2026-10-18.zip).

Сайт: https://ddintsen.github.io/-/?orbita-update=1. Репозиторий: https://github.com/ddintsen/-. История версий сохранена в Git; актуальный статус публикации — в начале HANDOFF.md.

Это аналитический интерфейс на React/Three.js с обычным и пространственным режимами. Сейчас отображаются демоданные. Оформление: космос, Земля, матовые стеклянные карточки с blur, светлая и тёмная темы; языки UA/EN/RU.

Проверьте:

- Desktop: ровная сетка3×3. Месячное количество/объём/«Разом» используют один слот; доступны10 самостоятельных фокусов. Заголовок и месяц стоят рядом.
- Графики: вертикальные месячные столбики с планом100%; простой показывает реальную длину на шкале0..10% с отметкой SLA5%. В исходном демосценарии две зоны внимания: Recycle7,2% и регулярные платежи84%; годовой YTD не создаёт месячные тревоги.
- Пространственный режим: три одновременных стенда по дуге, боковые повёрнуты на24°. Подписи/значения каналов видны, нижняя карточка оборудования широкая. Фокус показывает график и таблицу вместе, без страниц1/7.
- Последняя правка: «ПриватБанк | Орбіта» без подложки; логотип, текст и разделитель чёрные в светлой теме и белые в тёмной. Проверить читаемость на фоне, смену темы и клавиатурный focus.
- Обе темы и три языка на desktop и телефоне360/390px: читаемость, ховеры, отсутствие наложений и горизонтального переполнения. Нижней плавающей навигации нет.

Для каждой проблемы нужны скриншот, размер окна, тема, язык, шаги воспроизведения и ожидаемый результат. Проверяйте фактическое поведение: исходные документы содержат исторические указания, которые уточнялись пользователем. Текущие правила — последние записи DESIGN.md, UX-CONTRACT.md и DECISIONS.md.

Проверки WebGL выполнялись в браузере. Физический Quest3S и боевой API ещё не проверены; браузерные скриншоты не подтверждают оптику или FPS шлема.
