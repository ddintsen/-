# AI Agent Development & Documentation Rules (.cursorrules)
1. СТЕК: TypeScript, Vite, React 18, Three.js, @react-three/fiber, @react-three/drei (<Html transform>), @react-three/xr (v6), Zustand, Apache ECharts, TailwindCSS.
2. ОПТИКА META QUEST 3S: Линзы Френеля (1832x1920). Запрещен мелкий текст (<18px), тонкие шрифты и чисто белый (#FFFFFF) на черном (#000000). Использовать шрифт Inter (Medium/Bold/ExtraBold) с поддержкой кириллицы, табличные цифры (tabular-nums) и полупрозрачные темные панели (rgba(20, 25, 38, 0.78), border-radius: 24px).
3. БИЗНЕС-ЛОГИКА СПИДОМЕТРОВ:
   - Для годовых планов YTD (Дашборды 4, 6, 8, 9) значения 5–8% в начале года — это нормальный темп (лаймово-зеленая шкала).
   - Для простоев касс и оборудования (Дашборды 7 и 10) шкала ОБРАТНАЯ: <=2% изумрудный, 2.1–6.5% лаймово-желтый, >6.5% аварийный красный.
4. ДОКУМЕНТИРОВАНИЕ КАЖДОГО ШАГА:
   - После каждого промпта обновляй файл docs/WORKLOG.md (Этап -> Что сделано -> Файлы -> Как проверить -> Следующий шаг).
   - Над каждым компонентом пиши JSDoc с номером дашборда (@dashboard Д1..Д10).
   - Выдавай готовое сообщение коммита по стандарту Conventional Commits.
