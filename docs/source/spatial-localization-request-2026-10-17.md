# Задача: Редизайн и доработка пространственного 3D-дашборда «ОРБИТА» до уровня премиального Spatial UI + локализация (UA / EN)

Доработай существующий веб-интерфейс финансового дашборда «ОРБИТА» (десктопную и мобильную версии, модальное окно фокуса карточки и модальное окно настроек источников данных).

Цель — вывести визуальное исполнение и UX на уровень дорогого пространственного продукта (как в VR/MR-очках): парящие матовые стеклянные панели, ощутимая глубина, физически достоверный свет по граням, безупречная финансовая типографика и полная поддержка украинского и английского языков.

---

## 1. Визуальные и дизайн-референсы (Ориентиры стиля)

При стилизации компонентов опирайся на три референса:
1. **Apple visionOS (Human Interface Guidelines — Materials & Windows):**
   - Многослойное матовое стекло (`backdrop-filter: blur(28px) saturate(140%)`).
   - Направленный световой блик по ребру панели (Specular Rim): верхняя и левая границы карточки подсвечены ярче (`rgba(255, 255, 255, 0.22)`), нижняя и правая — затухают (`rgba(255, 255, 255, 0.05)`).
   - Глубокие мягкие тени (`0 24px 48px rgba(0, 0, 0, 0.45)`), отделяющие окна от 3D-интерьера комнаты.
   - Элементы управления (кнопки, переключатели, вкладки) в форме аккуратных капсул (pills) с чётким состоянием наведения.
2. **Meta Horizon OS (Spatial Panels & Ergonomics):**
   - Отсутствие «висящего в воздухе» мелкого текста поверх пёстрого 3D-фона без подложек.
   - Крупные интерактивные зоны нажатия (минимум 40×40 px) для комфортного попадания курсором или лучом в VR.
3. **Linear / Stripe Financial Dashboards (Dark Mode Data Viz):**
   - Табличные пропорции цифр (`font-variant-numeric: tabular-nums`), чистая иерархия сумм и процентов.
   - Компактные, информативные прогресс-бары и спарклайны вместо полупустых серых спидометров.

---

## 2. Неприкосновенные продуктовые требования
- **Сохранить 3D-кабинет и VR-стиль** на фоне.
- **Сохранить левую боковую вертикальную навигацию (док) на компьютере** — нижняя плавающая панель не нужна.
- **Обеспечить максимальную читаемость** финансовых показателей и графиков на любом фоне.

---

## 3. Мультиязычность: Украинский (UA) и Английский (EN) языки
Внедри полноценную систему интернационализации (i18n) с поддержкой **украинского (`UA`)** и **английского (`EN`)** языков (при необходимости оставь переключение между `UA / EN` или `UA / EN / RU`):
1. **Переключатель языка:** Добавь компактный стеклянный селектор языка (`UA` | `EN`) в верхнюю правую часть шапки (рядом со статусом данных и иконкой темы) и продублируй выбор языка в настройках. Сохраняй выбранный язык в `localStorage`.
2. **Полный перевод интерфейса без обрезаний текста:**
   - Переведи все заголовки, разделы навигации, подписи осей графиков, легенды, единицы измерения, периоды («Жовтень 2026» / «October 2026»), кнопки и модальное окно «Источники данных».
   - **Ключевой словарь терминов (UA / EN):**
     - Орбита → Орбіта / Orbita
     - Обзор → Огляд / Overview
     - Платежи → Платежі / Payments
     - Кассы / Кассовые операции → Каси / Касові операції / Cash Desks / Cash Operations
     - Оборудование → Обладнання / Equipment
     - Демоданные → Демодані / Demo Data
     - Кратко / Обновить → Стисло / Оновити / Brief / Refresh
     - Открыть в пространстве → Відкрити у просторі / Open in Space
     - За месяц / Количество / Объём / Вместе → За місяць / Кількість / Обсяг / Разом / Monthly / Count / Volume / Combined
     - Платежи по каналам (млн шт.) → Платежі за каналами (млн шт.) / Payments by Channel (M txns)
     - доля в ДБО / В отделениях → частка в ДБО / У відділеннях / Digital share / In branches
     - Количество платежей (Всего / Разовые / Регулярные) → Кількість платежів (Усього / Разові / Регулярні) / Payment Count (Total / One-time / Recurring)
     - Точные значения / Назад / Далее → Точні значення / Назад / Далі / Exact Values / Back / Next
     - Источники данных / Подключение API / Демонстрация → Джерела даних / Підключення API / Демонстрація / Data Sources / API Connection / Demo Mode
     - Проверить соединение / Сохранить подключение → Перевірити з'єднання / Зберегти підключення / Test Connection / Save Connection
3. **Адаптация верстки под длину слов:** На мобильном экране вкладки разделов («Огляд / Платежі / Каси / Обладнання» и «Overview / Payments / Cash Desks / Equipment») не должны сжиматься впритык или обрезаться — добавь плавный горизонтальный скролл контейнера вкладок или адаптивные внутренние отступы.

## 4. Конкретные визуальные и UX-исправления по экранам

### А. Материалы и пространственная глубина (Все экраны)
1. **Замена плоской заливки карточек:** Вместо глухого тёмно-серого фона задай всем карточкам и модальным окнам полупрозрачный градиент `linear-gradient(135deg, rgba(38, 41, 52, 0.72) 0%, rgba(24, 26, 34, 0.82) 100%)` с `backdrop-filter: blur(28px) saturate(140%)`, внутренним верхне-левым световым бликом `inset 0 1px 0 0 rgba(255, 255, 255, 0.22)` и глубокой тенью.
2. **Оформление текста поверх 3D-комнаты:** Заголовки колонок («Касові операції / Cash Operations», «Платежі / Payments», «Обладнання / Equipment») и блок даты («Жовтень 2026 / October 2026») сейчас висят прямо поверх светлого окна и паркета 3D-сцены. Оберни их в аккуратные полупрозрачные матовые капсулы (pills) с `backdrop-filter: blur(16px)` для стабильного контраста.

### Б. Сетка и композиция дашборда (Десктоп и Мобайл)
3. **Устранение разрыва сетки во 2-й колонке:** Убери строку фильтра `За месяц` и переключатель `Количество / Объём / Вместе`, которые сейчас лежат прямо на фоне деревянного пола между карточками «Платежи по каналам» и «Количество платежей». Встрой этот сегментированный переключатель внутрь шапки соответствующей карточки, а верхние и нижние границы карточек во всех трёх колонках выровняй по единой модульной сетке.
4. **Баланс кнопки «Открыть в пространстве»:** Замени сплошную ярко-белую заливку кнопки «Открыть в пространстве» на премиальную полупрозрачную стеклянную капсулу с акцентным свечением контура и белым текстом, чтобы она не перебивала визуальный вес самих графиков. На мобильном экране верни понятный баланс кнопкам «Кратко» и «Обновить».

### В. Графики, типографика и демоданные
5. **График «Количество платежей»:**
   - Подними пунктирную линию `план 100%` выше столбцов так, чтобы она НЕ пересекала число `84%` над третьим столбцом («Регулярные»).
6. **График «Платежи по каналам»:**
   - Увеличь расстояние между парами соседних столбцов, чтобы подписи значений сверху (`32,1` и `31,4`, `31,8` и `29,5`) не слипались.
   - Исправь усечение подписи `Автоплат.` на оси X (используй читаемое сокращение или двухстрочную подпись).
7. **Карточка «Состояние оборудования» и линейные графики:**
   - Устрани рассинхрон названий: в легенде графика указано `Recycle`, а на нижнем индикаторе простоя оно обрезано до `Rec` — приведи к единому полному названию `Recycle`.
   - Увеличь размер шрифта подписей оси Y (`1,2 тыс.`, `2,4 тыс.`, `4,8 тыс.`) минимум до `12px` и повысь их контрастность до `rgba(255, 255, 255, 0.65)`.
8. **Замена 13 монотонных полукруглых спидометров и исправление дублей в демоданных:**
   - В карточках «Кассы с начала года», «Платежи с начала года», «Операции устройств», «Объём операций устройств» и «Простой» сейчас используются полупустые серые дуги с почти одинаковыми значениями (`5,2%`–`8,3%`), которые выглядят однообразно и занимают много пустого места. Замени их на информативные горизонтальные прогресс-бары (или компактные полные кольца) с чётким отображением факта, плана и статуса.
   - Устрани дублирование цифр в демоданных: сейчас в «Кассах с начала года» и «Платежах с начала года» стоят одинаковые суммы (`76,1 млн` и `247,5 млн`), а в колонке «Оборудование» пять раз подряд повторяется цифра `6,2%`. Задай реалистичные уникальные значения для каждой метрики.

### Г. Раскрытая карточка (Модальное окно фокуса)
9. **Полезная плотность и компоновка в режиме фокуса:**
   - В правой части окна сократи пустой разрыв между крупными числами (`55,1 млн`, `32,6 млн`, `22,5 млн`) и мини-графиками трендов (`+4,2%`, `+3,8%`, `+1,9%`), оформив каждую строку показателя как единую аккуратную плашку.
   - Таблицу `▸ Точные значения` в раскрытом модальном окне показывай сразу развёрнутой по умолчанию, чтобы полноэкранный режим давал больше аналитики, чем превью на дашборде.
   - Кнопки переключения `← Назад`, `Далее →` и кнопку закрытия `×` оформи как заметные стеклянные кнопки-капсулы высотой `40px` с понятным hover-эффектом.

### Д. Навигация и модальное окно «Источники данных»
10. **Боковой док на компьютере:** Сохрани текущую левую вертикальную панель, но добавь всплывающие стеклянные тултипы с названиями разделов при наведении (или компактные подписи), а также приведи к единой логике расположение иконок помощи `?` и настроек между десктопом и мобильной версией.
11. **Окно «Источники данных»:**
    - Синхронизируй верхние вкладки (`Подключение API` / `Демонстрация`) с формой ниже: когда выбрана вкладка `Подключение API`, в селекте «Источник» не должно одновременно висеть противоречащее значение `Демоданные` (раздели состояния: в режиме «Демонстрация» скрывай или деактивируй поля `Адрес API` и `Bearer token`).
    - Убери грубую двойную рамку фокуса вокруг выпадающего списка «Источник», заменив её на аккуратное одинарное свечение `1.5px solid rgba(168, 162, 255, 0.7)`.
