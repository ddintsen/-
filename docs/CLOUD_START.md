## start_skill

Проект ОРБИТА расположен в /workspace/-. Используйте существующий checkout: каждая cloud-задача уже изолирована; не создавайте git worktree без явного запроса пользователя.

Сначала прочитайте CONTEXT.md, docs/WORKLOG.md, docs/DECISIONS.md и README.md. Сохраняйте новые решения и результаты проверок в журнале по мере работы, не дожидаясь потери контекста. Исходное ТЗ находится в docs/SPEC.md, HTML-прототип в docs/source/ — справочный материал, не активное приложение.

Подготовленные node_modules, dist, локальные шрифты и XR controller profiles могут сохраняться в снимке; процессы не сохраняются. При необходимости восстановить зависимости выполните install_script (или bash scripts/cloud-install.sh). Node.js >=22.12; npm cache в /workspace/.npm. Не меняйте зависимости и lockfile только ради настройки среды. Не создавайте и не сохраняйте секреты в файлах.

Для разработки: cd /workspace/-; npm run dev. Сервер слушает 0.0.0.0:5173. Сначала проверьте, нет ли уже запущенного процесса этой задачи; не останавливайте чужие процессы. Проверка: локальный GET / и /mock/dashboard-data.json, затем npm run test:e2e (используется /usr/bin/chromium; CHROMIUM_PATH допускает другой установленный Chromium). Успех: 10 карточек через переключатель «Вместе», фокус открывается/закрывается, ошибок JS нет. Не создавайте пользовательские ссылки на localhost в onboarding UI.

Production: npm run build, затем npm run preview -- --port 4173. Проверки: npm run typecheck; npm run test; npm run tokens:check; npm run format:check; npm run test:e2e. Для внутренней HTTPS-разработки npm run dev:https -- --port 5174; проверяйте с curl --cacert node_modules/.vite/basic-ssl/_cert.pem https://localhost:5174/. Самоподписанный dev-сертификат не является доверенным для Quest: аппаратный WebXR требует доверенного HTTPS-хоста.

По умолчанию работают демоданные, без внешнего API, БД или ключей. Настройки через ?admin=1. Токен только в памяти вкладки, не логировать и не переносить в инструкции. Для реального API нужен разрешённый HTTPS endpoint и CORS либо согласованный dev proxy API_PROXY_TARGET. Синхронизация demo работает между вкладками одного браузера/origin, не между ноутбуком и шлемом. Настоящие AR/VR, pinch/контроллеры, оптика и частота кадров требуют проверки на Quest 3S. Нативный APK и публикация не выполнены.

Конфигурация и локальные файлы подготовлены, но не объявляйте среду опубликованной или восстановленной в новой задаче без фактической проверки.
