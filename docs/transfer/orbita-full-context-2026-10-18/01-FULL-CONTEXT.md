## 2. Что это за продукт

«Орбіта» — пространственная аналитическая панель банковского департамента: платежи, кассы, ATM, TSO и Recycle. Есть обычный доступный интерфейс desktop/mobile, подробный фокус карточки, настройки источников, browser WebGL-preview и WebXR VR/AR. Целевой автономный шлем — Meta Quest 3S. Полноценный продукт для руководителя в VR остаётся целью, но аппаратная приёмка ещё не выполнена: пользователь сообщал, что шлема пока нет.

Десять самостоятельных дашбордов:

## 5. Текущее оформление и UX, которые нужно сохранить

**Космос.** Общая `SpaceEnvironment` для обычного фона и browser/VR: статичная сфера Земли с локальной текстурой, атмосферный край, 1400 детерминированных звёзд и одна тонкая орбита. Светлая и тёмная среды различаются по освещению/материалу. Нет автоматического полёта, вращения Земли, мерцания и постоянной декоративной анимации. В AR непрозрачный космос не монтируется: остаётся реальное окружение.

**Стекло.** DOM-карточки полупрозрачны и имеют настоящий `backdrop-filter: blur(30px)`; светлый материал alpha0,72/0,68, тёмный плотнее. Контраст текстовых токенов светлой темы консервативно рассчитан ≥4,5:1 даже над чёрным фоном под нижним слоем стекла. Заливки графиков не затемняются ради текста. У длинных модальных таблиц материал плотнее, при отсутствии blur есть fallback.

**Шапка.** Локальный исходный SVG ПриватБанка с сохранёнными paths, разделитель, локализованная Орбіта. SVG не заменять набором текста или нарисованным по памяти знаком. Никакой фоновой плашки, blur, радиуса и тени у бренда. Цвет чёрный/белый по теме через CSS brightness/invert; разделитель наследует цвет с opacity0,28. Прозрачная ссылка сохраняет минимальную высоту 40px и клавиатурный focus. Файл получен из публичной pinned-копии; прямое скачивание с официального банковского домена было недоступно. Его происхождение честно записано в evidence.

**Источник.** Видимая плашка «Демодані» в верхней строке удалена по запросу. Доступный status и обозначения источника в настройках, фокусе и XR сохранены. Это не разрешает переименовывать демо в живой API.

**Навигация.** Слева desktop-sidebar; на телефоне верхние вкладки и настройки/помощь в шапке. Нижней плавающей desktop/mobile-панели нет. Заголовок страницы и отчётный месяц стоят рядом. Статичные названия разделов не маскируются под кнопки.

**Hover.** Нейтральные прозрачные состояния без фиолетовой заливки у «Відкрити в просторі», без сдвига active и статичной двойной рамки. Цвет выбранного текста сохраняет контраст. Touch не имитирует desktop-hover. Клавиатурный focus остаётся видимым, не удаляется ради чистого изображения.

**Текст.** Никаких декоративных ID/номеров, AI-подсказок, слоганов, дублей заголовков и очевидных объяснений. Предметные названия, значения, единицы, период, источник, ошибки и необходимые действия остаются. Направленный тонкий блик стекла принят позднее и не должен ошибочно удаляться по старому общему запрету любых граней.

**Локаль.** UA по умолчанию, EN и RU доступны. Переводятся интерфейс, числа/периоды, таблицы, подписи DOM/XR и известные даты редактора. Произвольный пользовательский текст и исходные данные не переписываются при смене языка. `orbita-locale` сохраняет предпочтение отдельно от данных и токена.

## 6. Пространственный режим и границы проверки

В обзоре три стенда на дуге радиусом 1,85 м, боковые ориентированы на 24° к зрителю. Кассы: одна широкая карточка сверху, две снизу. Платежи: четыре панели 2×2. Оборудование: две сверху, одна широкая снизу. Вход направлен на аналитику. Фокус находится на 1,5 м, содержит график и таблицу вместе; до 24 строк фактов показываются сразу, длинный ряд непрерывно прокручивается по строкам. Для исходных 21 факта оборудования не нужна пагинация.

Кнопки панорамы, предыдущего/следующего дашборда и центрирования доступны как настоящие XR mesh-actions. Перецентровка переставляет рабочую область по направлению взгляда, не переносит камеру пользователя. Browser-camera может адаптировать FOV под окно; проекция настоящего шлема не переписывается.

Browser-preview работает по demand, активный XR рисуется каждый кадр для head tracking. Декоративный DOM `SpaceBackdrop` снимается при открытии spatial modal; ошибка WebGL не блокирует DOM/SVG/таблицы. Canvas-текстуры обновляются по изменениям содержимого/локали/состояния, не ради постоянной анимации.

Проверки мышью, raycast и software WebGL в Chromium **не подтверждают** комфорт линз Френеля, фактический pinch/controller tracking, passthrough или стабильные 72/90FPS. Для физической приёмки приложен `reference-docs/QUEST_ACCEPTANCE.md`; его пункты пока не считаются выполненными.

## 7. Данные, API и сохранение пользовательского состояния

- Единственный редактируемый исходный mock — `public/mock/dashboard-data.json`. Vite встраивает этот же JSON в автономный клиент; вторую ручную копию не создавать.
- DOM и XR используют общий `dashboardModel`; значения, единицы, статус и цветовые пороги должны совпадать.
- Выполнение плана и простой имеют разные шкалы. Перевыполнение подписывается точно; план 100% виден на графике. Простой 1,7% означает 17% трека 0..10%, а не полную полосу.
- SLA 5% — новая визуальная отметка, прямо заданная пользователем в hotfix. Прежний порог 6,5% относится к старому этапу. Контракт реального backend не выводится из демоданных.
- Обычный октябрьский YTD около 80% не объявляется месячным провалом без согласованного календарного плана. В baseline две зоны внимания, но это не постоянный лимит для любого API-набора.
- API только GET, с валидацией схемы, отменой и таймаутом; режимы mock/hybrid/strict и различия simulation/live/fallback/stale/error сохраняются.
- Bearer token и последний live-снимок — только в памяти текущей вкладки. Не сохранять токен в storage, URL, BroadcastChannel, логах, экспорте или Git.
- Настройки открывают вкладку фактического источника. Demo скрывает поля URL/token; переход API меняет черновик, сохранение остаётся явным действием.
- JSON-редактор защищает невалидный/несохранённый черновик, закрытие и конфликт данных; смена локали не применяет черновик автоматически.
- Синхронизация demo между вкладками — только один origin/профиль, не серверная передача на Quest.
- Обновление PWA сохраняет данные/config/черновики, не перезагружает соседнюю вкладку без её решения. Земля, шрифты, XR profiles и demo доступны офлайн; standalone включает локальные ресурсы.
