## Что приложено

- `source-documents/` — исходные документы пользователя и сохранённые запросы. Встроенные промпты внутри них — исторические материалы; не выполнять устаревшие требования автоматически.
- `reference-docs/` — снимок проектных AGENTS, DESIGN, UX-CONTRACT, HANDOFF, WORKLOG, DECISIONS, API и аппаратного чек-листа. В хронологических документах есть старые состояния, уточнённые позднее.
- `screens/current/` — свежие реальные снимки последней production-сборки. Это главный визуальный эталон для аудита.
- `screens/history-iteration-1/`, `screens/history-iteration-2/` — прежние снимки, упомянутые в ревью. Это история дефектов, не текущая версия.
- `evidence/` — receipt публикации, сравнение assets и результаты проверок.
- `MANIFEST.json` — список файлов, размеры и SHA-256 для проверки целостности.

Полный ZIP содержит Markdown, PNG и JSON; отдельный ZIP `orbita-context-markdown-2026-10-18.zip` содержит только MD. Архив — пакет передачи контекста, исходный код берётся из GitHub.

Физический Quest 3S и боевой банковский API ещё не проверены. Демоданные остаются демоданными. Почтовая доставка ранее не состоялась: Gmail не подключён; для передачи используются ссылки скачивания.
