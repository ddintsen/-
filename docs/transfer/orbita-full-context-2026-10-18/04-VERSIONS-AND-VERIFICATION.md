- Физический Meta Quest 3S отсутствовал: оптика,6DoF tracking,Touch Plus,pinch,passthrough и FPS не измерялись. Протокол приёмки приложен отдельно.
- Боевой endpoint/учётные данные не предоставлены. Сейчас демо; backend SLA и фактические планы надо согласовать отдельно.
- Прямой github.io из cloud блокировался CONNECT403. Успешный live-доступ проверялся GitHub Actions, receipt подтверждает точный runtime и assets.
- Четыре пользовательских inline-фрагмента доступны только в чате, бинарных файлов в пакете нет. Они описаны без подмены.
- Gmail не подключён, письмо с архивом не отправлено. Ранее проблема скачивания решалась публичной HTTPS-ссылкой; такой же способ используется для этого пакета.
- Canvas справа из присланного сообщения не был доступен; его содержимое сверх приложенного текста не восстанавливается по догадке.
