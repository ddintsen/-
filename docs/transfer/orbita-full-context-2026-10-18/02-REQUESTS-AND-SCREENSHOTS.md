## 1. Источники и границы достоверности

Это восстановление задач по доступной переписке, двум загруженным файлам и истории репозитория. Здесь отделены прямые поручения, вложенные сторонние ревью, фактические снимки и исторические состояния. Дословная полная стенограмма всех старых сообщений не заявляется. Оригинальные вложения включены целиком.

## 7. Матрица итоговых требований

| Требование | Статус в последней версии | Проверка аудитора |
| --- | --- | --- |
| Desktop 3×3 и 10 независимых дашбордов | Реализовано:9 слотов, общий месячный слот | Переключить количество/объём/Разом; убедиться, что высота сетки стабильна |
| Вертикальные месячные графики | Реализовано в DOM/XR/фокусах | План 100% не пересекает 90,7/96/84%, текст не слипается |
| Простой 0..10%, фактическая длина, SLA 5% | Реализовано | Сравнить 1,7 и 7,2; не путать с планом |
| Не засорять attention годовым YTD | Реализовано | В baseline2 чипа: Recycle7,2 и регулярные 84 |
| Три одновременных XR-стенда | Реализовано | Кассы/платежи/оборудование видны вместе; боковые 24° |
| Каналы/значения и график оборудования | Реализовано | Все 6 каналов; широкая нижняя карточка и линии |
| Один XR-фокус с графиком и фактами | Реализовано | Нет 1/7,21 baseline-факт, длинный ряд скроллится |
| Точные планы без выдуманных чисел | Реализовано | При отсутствии planValue явно «Не передано» |
| UA/EN/RU и локализованные даты редактора | Реализовано | Нет автоматической записи JSON или потери черновика |
| Настройки API/Demo и token memory-only | Сохранено | Действующий источник согласован с формой, секрет не сохраняется |
| Пустая комната в двух темах | Сделано как промежуточная версия, затем заменено пользователем | Не возвращать её как последнее требование |
| Космос и стеклянные панели с blur | Реализовано и опубликовано | Обе темы, читаемость над Землёй, offline, AR без непрозрачного фона |
| Убрать видимую «Демодані» | Реализовано | Шапка без капсулы, достоверные статусы источника в продукте сохранены |
| Заголовок и месяц в ряд | Реализовано | Desktop и 360/390px, без наложений |
| Настоящий логотип ПриватБанка + разделитель + Орбіта | Реализовано локальным исходным SVG | Пути/пропорции сохранены, изображение загружено |
| Бренд без подложки, цвет по теме | Последняя правка, опубликована | Чёрный в light, белый в dark, без заливки/blur/тени |
| Hover без фиолетовой заливки и двойной рамки | Реализовано | Мышь/клавиатура/тач, stable bounds, читаемый selected |
| Полноценный VR на физическом Quest 3S | Ещё не проверено аппаратно | Пройти отдельный протокол, не переносить PASS браузера на шлем |
| Боевой API | Не предоставлен и не проверен | Нужен согласованный endpoint/контракт отдельно от демо |
